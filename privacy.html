プライバシーポリシー

Stillframe Radio Pipeline ／ 最終更新日: 2026年10月20日

1. 対象

本ポリシーは、YouTube チャンネル「Stillframe Radio」の運営者（以下「運営者」）が自身のチャンネル運用のために使用するツール「Stillframe Radio Pipeline」（以下「本ツール」）における Google ユーザーデータの取り扱いを定めます。本ツールの利用者は運営者本人のみです。

2. 取得する情報

  • 運営者の YouTube チャンネル情報（チャンネルID、チャンネル名、公開状態、動画数などの統計）
  • 運営者のチャンネルの動画情報（タイトル、説明文、公開状態、公開予定日時）
  • 運営者のチャンネルの YouTube アナリティクス指標（再生回数、総再生時間、クリック率など）
  • Google の認可に必要な OAuth トークン

3. 利用目的

取得した情報は、運営者自身のチャンネルへの動画のアップロード、メタデータの管理、公開予約、運用成績の確認のためだけに使用します。広告、プロファイリング、その他の目的には使用しません。

4. 保存と管理

情報は運営者の管理するコンピュータ上にのみ保存します。OAuth トークンはアクセス権限を運営者本人に限定したファイルに保存し、ソースコード管理やログには含めません。

5. 第三者提供

Google ユーザーデータを第三者に販売・提供・共有することはありません。人が閲覧するのは運営者本人のみです。

6. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。YouTube API の利用には YouTube 利用規約 および Google プライバシーポリシー が適用されます。

7. アクセス権の取り消しと削除

本ツールへのアクセス権は Google アカウントの権限設定 からいつでも取り消せます。取り消し後、または運営者の判断により、保存した情報とトークンを削除します。

Privacy Policy

Stillframe Radio Pipeline / Last updated: October 20, 2026

Stillframe Radio Pipeline (“the tool”) is used only by the operator of the YouTube channel “Stillframe Radio” to manage that channel.

Data accessed: the operator's YouTube channel details and statistics, video metadata (title, description, privacy status, scheduled time), YouTube Analytics metrics for the operator's channel, and OAuth tokens required for authorization.

Use: solely to upload and manage videos and metadata on the operator's own channel and to review its performance. No advertising, profiling or other uses.

Storage: only on the operator's own computer; OAuth tokens are stored in files readable only by the operator and are never committed to source control or written to logs.

Sharing: Google user data is never sold, transferred or shared with third parties.

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revocation and deletion: access can be revoked at any time at Google Account permissions; stored data and tokens are then deleted.
